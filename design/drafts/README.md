# Drafts

Unfinished looks that are not built and not shipped: `sprout` and `ghoul` (a garden theme: a plant's eye by
day, a zombie's eye by night) and `astral` (Sirius, a cosmic animal's eye in flat drawing).

To work on one again, move its `shaders/<id>.glsl` to `shaders/src/` and its `skins/<id>.json` to `skins/`,
add the id to `skins/order.json` and run `python3 tools/build.py`.
