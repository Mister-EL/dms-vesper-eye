# Поведение и визуальный язык

## Образ
Vesper — спокойный ночной хранитель, не маскот с непрерывными случайными движениями. Оккультный городской нуар, вампирская готика и тонкая геометрия ар-деко. Оригинальный дизайн без извлечённых игровых ассетов.

## Взгляд
- Главная выразительность — в движении радужки, зрачка и век, не всего виджета.
- Лёгкая физиологическая задержка перед переводом внимания; короткий быстрый перевод и мягкое затухание. Без длинного резинового шлейфа.
- Критически затухающее движение, расчёт по delta time; одинаковая траектория на 60/120 Гц. Не задавать скорость числом кадров.
- Слои движутся не идентично: радужка ведёт взгляд, зрачок немного отстаёт, веки подстраиваются. Смещения малы и ограничены формой глаза.
- Микросаккады редкие и маленькие, а не постоянная дрожь. На неподвижном указателе не гонять весь renderer без причины.
- Взгляд может ненадолго отлипнуть от мыши и спокойно вернуться; не отслеживать лицо/окна с личным содержимым.

## Веки и моргание
- Закрытие быстрее открытия; верхнее веко делает основное движение, нижнее слегка участвует.
- Интервал варьируется, иногда двойное моргание; cooldown после ручной реакции. Не мигать каждый тик таймера.
- Во время перевода внимания моргание может быть естественной связкой, но не блокирует реакции.
- Дремота: постепенное полузакрытие и редкие короткие осмотры, затем почти статичный покой.
- При пробуждении один короткий blink и фокусировка; не проигрывать накопившиеся события.

## Состояния и приоритеты

| Состояние | Вход | Реакция |
|---|---|---|
| Suspended | Плагин выключен, lock, DPMS off | Нет кадров анимации и cursor polling; при возвращении переинициализация времени |
| Reduced motion / Quiet | Настройка, DND/presentation | Статичный или очень сдержанный взгляд, системные реакции приглушены |
| Manual reaction | Локальный клик по глазу вне edit mode | Короткий blink/внимание; никогда не системная опасная команда |
| Notification glance | Разрешённое событие, cooldown завершён | Один взгляд в нужную сторону, потом возврат; без чтения текста |
| Attentive | Недавнее движение мыши | Мягкое слежение, малые саккады |
| Curious | Редкий короткий idle-эпизод | Небольшой взгляд в сторону, изменение века, возврат |
| Drowsy | Длительное отсутствие активности | Полузакрытые веки, уменьшение движения |
| Resting | Обычный покой | Неподвижная основа, редкое моргание |

Приоритет: suspended > reduced-motion/edit > manual > bounded notification > attentive > idle. Реакции не накладываются бесконтрольно; события объединяются, устаревшие отбрасываются. Настроение — простая state machine, не модель ИИ.

## Визуал
- Склера приглушённая костяная, не белая. Радужка — тёмный гранат с тонким внутренним тёплым кольцом; зрачок почти чёрный.
- Добавить лимбальное кольцо, мягкую тень верхнего века, одну-две устойчивые световые точки. Блики не скачут случайно вместе с указателем.
- Тонкие радиальные волокна радужки: предвычисленная небольшая текстура либо недорогая аналитика. Не многослойный процедурный шум на всю поверхность каждый кадр.
- Сохранить выразительный вытянутый силуэт; форма века/маска обеспечивает чистый край на разных scale.
- Микро-параллакс и маленькое изменение зрачка делают глубину. Не нужен дорогой full-screen blur.
- Палитра не кодирует ошибки системы одним цветом глаза: реальное сообщение остаётся в штатном UI. Глаз — декоративное дополнение, не единственный индикатор.

## Музыка
Опционально: слабое изменение радужки/зрачка по сглаженной энергии. Не эквалайзер, не стробоскоп. После паузы spectrum подписка закрывается; на батарее выключено по умолчанию. Никакого микрофонного прослушивания.

## Настройки
Три preset: Calm (по умолчанию), Lively, Minimal. Независимо: follow cursor, blink intensity, host theme vs собственная палитра, notification reactions, music, power policy. Отдельный reduced-motion override. Размер и положение — средствами desktop editor DMS.
