# Как добавить образ

Образ — это два файла.

1. `shaders/src/<id>.glsl` с функцией `vec4 eye(vec2 q)`.
   - `q` — точка в единицах глаза: 1 — половина высоты раскрытия у «Смотрителя», ось y вниз; весь холст 5.7×2.7.
   - Возвращается цвет с предумноженной альфой; вне рисунка — прозрачно.
   - Общая анатомия лежит в `common.glsl`: `eyLids` (кромки век с перекосом, улыбкой и печалью), `eyIris` (радужка на шаре и зрачок, смещённый в сторону взгляда), `sdLens`, `arcBelow`. Ими пользоваться не обязательно: архивные образы рисуют свою форму сами.
   - Шейдер собирается и под OpenGL ES 1.00, поэтому без побитовых операций, `round`, `switch`, текстур и циклов с непостоянной границей. Слова `active`, `half`, `flat`, `smooth`, `sample` заняты.
2. `skins/<id>.json` по образцу `skins/keeper.json`:
   - `title`, `note`, `shader` — имя файла шейдера без расширения;
   - `restLid` — насколько прикрыто верхнее веко в покое;
   - `shape` — форма глаза для попадания мышью и расчёта перекрытия окнами: `{ "type": "lens", "w": полуширина, "hu": высота вверх, "hl": высота вниз }`;
   - `character` — характер: темп, резвость взгляда, моргание и веса номеров из `core/Acts.js`; описание полей в [ARCHITECTURE.md](ARCHITECTURE.md);
   - `variants` — `dark` и `light`: восемь цветов `colors` для слотов `uC0`…`uC7`, при желании числа `p0` и `p1`, палитра страницы `page` для доски.

Затем добавьте `<id>` в `skins/order.json` и запустите `python3 tools/build.py`. Образ появится в настройках плагина и на доске `design/board/index.html`.

Смотреть результат удобно снимками: `tools/shot.sh out.png 950 450 'solo=<id>&gx=0.5&gy=0.2&lt=0.1&bg=000000'`. Параметры: `gx gy` взгляд, `px py` запаздывающий взгляд, `lt lb` веки, `pupil`, `wake`, `pulse`, `dim`, `mood`, `face`, `pose`, `p0`, `p1` (по четыре числа через запятую), `variant`, `bg`.
