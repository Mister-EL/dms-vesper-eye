# Устройство

```text
plugin.json, Settings.qml
VesperEye.qml          связка с оболочкой: настройки, положение на экране, уведомления, музыка, блокировка
core/Presence.qml      сколько глазу можно тратить: виден ли он, за компьютером ли человек, питание
core/CursorSource.qml  позиция указателя из сокета Hyprland; над самим глазом — события окна
core/Gaze.qml          взгляд: пружина без перерегулирования, порог видимого изменения, предел кадров
core/Manner.qml        веки, зрачок, дремота, сон, реакции
core/EyeView.qml       отрисовка: один шейдер на образ
core/Coverage.js       геометрия глаза и расчёт перекрытия окнами
skins/<образ>.json     описание образа: палитры, характер движения
shaders/src/           исходники шейдеров: common.glsl и по файлу на образ
tools/build.py         сборка: .qsb для Qt, skins/SkinData.js, design/board/index.html
```

## Расход по состояниям

| Состояние | Опрос указателя | Кадры |
|---|---|---|
| Закрыт окнами, полноэкранное окно, блокировка | нет | нет |
| Виден, человек не трогает компьютер дольше 3 с | нет | редкое моргание |
| Виден, указатель стоит | 4 раза в секунду | нет |
| Виден, указатель движется | 30 раз в секунду, 20 в экономичном режиме | при заметном изменении, не чаще предела |

«Закрыт окнами» значит, что окна активного рабочего стола закрывают не меньше 85% глаза: узкая щель между окнами не в счёт. Геометрия окон запрашивается у Hyprland при событиях окон; при любой неясности глаз считается видимым.

Вне Hyprland позиции указателя нет: глаз реагирует на указатель только над собой, остальное поведение сохраняется.

## Параметры шейдера

Все образы получают один и тот же набор (`shaders/qt/header.glsl`): взгляд `uGaze` и он же с запаздыванием `uGaze2`, зрачок `uPupil`, веки `uLidTop` и `uLidBot`, пробуждение `uWake`, событие `uPulse` с направлением `uPulseDir`, музыка `uEnergy`, яркость `uDim`, вариант `uLight`, восемь цветов `uC0`…`uC7`. Время `uTime` движок не двигает: непрерывной анимации нет.

## Проверка

- `tests/tst_core.qml` — взгляд, поведение, геометрия; запускается без экрана.
- Шейдеры проверяются по снимкам доски (`tools/shot.sh`) и сборкой `qsb` под все цели.
- Загрузка в оболочке проверена во вложенном сеансе Hyprland на Dux Shell 2.1.2 и DMS 1.6.0.
